# Créditos

BAIOS (*Blinter All In One Security*) es un proyecto de **Andago**. Contacto: [blinter.baios@gmail.com](mailto:blinter.baios@gmail.com).

Logos de marca: colaboración de **velosergio**.

El software de terceros es propiedad de sus autores. BAIOS solo agrupa ediciones gratuitas o de prueba; cada fabricante aplica su propia EULA. Este archivo es la **atribución** (quién, qué versión se citó, licencia). Las fichas de producto y la vigencia para BAIOS 4 están en el [catálogo](catalogo.md).

Licencia del código de BAIOS: [GNU GPL v3](../LICENSE).

Fuente: notepads de créditos (~marzo 2020, AIO 2021-08-19 y AIO 2022-01-05), fusionados con [`archive/Creditos.md`](archive/Creditos.md) y con la atribución ya documentada aquí. Si un programa aparece más de una vez, se conservan **todas** las versiones citadas; no se elige una sola. Esas versiones son históricas: no sustituyen al catálogo ni al binario actual.
